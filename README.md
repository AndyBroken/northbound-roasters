# Northbound Coffee Roasters — Standard Package (Concept)

Multi-page business website for a specialty coffee roastery in Portland, OR.

**Pages:** Home · Our Coffee (catalog with roast filter) · Product detail (dynamic, image gallery) · About (values, timeline, team) · Journal (blog with categories) · Contact & Wholesale (switchable form, map, FAQ accordion).

**Highlights:** shared header/footer components, data-driven product & blog cards, custom SVG packaging, newsletter forms with validation, SEO meta tags, responsive layout.

**Tech:** HTML5, CSS3, vanilla JavaScript. Photos: Unsplash.

*Concept / demo project — Northbound is a fictional brand.*
